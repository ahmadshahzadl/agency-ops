# Software House Management System — Development Roadmap

This roadmap breaks the system into phases and concrete tasks for the **backend**, **frontend**, and **integration** agents. Tasks are executed in order; each phase should be completed before moving to the next. All task handoffs are written in `/tasks/current-task.md`.

---

## Phase 1: Foundation — Authentication & RBAC

**Goal**: Secure auth (JWT) and role-based access so all later modules can enforce permissions.

| # | Area | Task | Agent |
|---|------|------|--------|
| 1.1 | Backend | Set up project: FastAPI app, config (env), database connection, Alembic. | backend |
| 1.2 | Backend | Implement `users`, `roles`, `permissions`, `user_roles`, `role_permissions` models and migrations. | backend |
| 1.3 | Backend | Auth: register, login (password hash verify), JWT access + refresh token issue. | backend |
| 1.4 | Backend | RBAC: dependency that loads user + permissions and checks permission code per route. | backend |
| 1.5 | Backend | Endpoints: `POST /auth/login`, `POST /auth/refresh`, `GET /me`; optionally user/role CRUD (admin). | backend |
| 1.6 | Integration | API client base (base URL, interceptors), auth token attach and refresh, typed auth types. | integration |
| 1.7 | Frontend | Login page, store tokens securely, redirect by role; role-based route guard. | frontend |
| 1.8 | Frontend | Shell layout: sidebar/nav driven by permissions; logout. | frontend |

**Exit criteria**: User can log in, receive JWT, and see only allowed nav/actions based on role.
